# Quick Reference

The must-know list for the last day before an interview. For each item, be able to give the **definition**, a **short example**, and one **pitfall**.

---

## Core Java
- `==` vs `equals()`
- String immutability
- `final`, `finally`, and `finalize()` (`finalize` is deprecated for removal)
- Widening vs narrowing casting
- Checked vs unchecked exceptions

## OOP
- Runtime vs compile-time polymorphism
- Abstract class vs interface
- Why a class cannot extend two classes, and how default methods change the picture
- SOLID principles at a basic level

## Collections
- How `HashMap` works: hashing, buckets, collisions, treeification
- `List` vs `Set` vs `Map`
- `Comparable` vs `Comparator`
- `ConcurrentHashMap` vs `HashMap`

## Java 8 and later
- Stream vs collection
- `map` vs `flatMap`
- Optional: use it for return values, not for fields or parameters
- Functional interface: exactly one abstract method

## Multithreading
- `Runnable` vs `Thread`
- Synchronisation
- Deadlock: the four conditions and how to avoid them
- `volatile` vs `synchronized`

## JVM
- Heap vs stack
- GC types and when each one suits a workload
- JIT compiler

---

## Last-Hour Checklist

- [ ] Explain one design pattern with a real example
- [ ] Explain one SQL query with a join and an aggregate
- [ ] Describe one project you built, in STAR form
- [ ] Name three ways to make an API safe to retry
- [ ] Say what happens on a Spring Boot startup, in three steps
