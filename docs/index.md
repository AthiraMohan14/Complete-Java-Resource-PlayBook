## How to Use This Playbook

1. Follow the roadmap in phase order. The DSA track runs in parallel.
2. For each topic, learn the idea, write a small example, and explain it aloud.
3. Use the must-know checklist before interviews.
4. For round-by-round tips and STAR answers for behavioural rounds, read [Interview Questions](interview-questions/index.md).
5. Use the search bar at the top of the page to find a specific topic, class, or annotation quickly.
