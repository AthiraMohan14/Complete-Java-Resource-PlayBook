# Additional Specialisations

These topics are taken up as your work or interests require them. Each one extends the core backend skills: searching large text collections, building data systems that scale beyond a single database, and serving machine learning models from Java services.

---

## Topics

### [Search and Analytics](search-analytics.md)
**Elasticsearch - inverted index - aggregations - Solr - OLAP - data warehouses**
Build full-text search with relevance tuning, and understand how analytical workloads differ from transactional ones.

### [Advanced Patterns](advanced-patterns.md)
**event sourcing - CQRS - sagas - Temporal - Kafka Streams - Flink**
Handle distributed consistency, separate reads from writes, and process event streams.

### [Machine Learning for Backend Engineers](ml-for-backend-engineers.md)
**training - features - evaluation - model serving - DJL - ONNX Runtime - TensorFlow.js**
Understand the ML lifecycle well enough to serve models behind an API and work with the people who train them.
