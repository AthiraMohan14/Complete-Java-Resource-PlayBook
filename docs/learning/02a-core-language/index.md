# Core Language

The object-oriented core of Java: wrapper classes and strings, classes and encapsulation, inheritance and interfaces, enums and nested types, exceptions, and generics. These topics appear in almost every Java interview, and the later collections and framework material assumes you know them.

---

## Topics

### [Wrappers, Strings and Arrays](wrappers-strings-arrays.md)
**Integer - autoboxing - Math - String - StringBuilder - equals - Arrays**
Wrapper classes and autoboxing, the `Math` and `Character` utilities, immutable strings versus builders, `==` versus `equals()`, and one- and multi-dimensional arrays.

### [Classes, Objects and Encapsulation](oop-classes-encapsulation.md)
**constructors - this - initialization order - composition - aggregation - getters and setters**
Defining classes and objects, constructor chaining, static and instance initializer order, and hiding state behind an API.

### [Inheritance, Polymorphism and Interfaces](inheritance-polymorphism-interfaces.md)
**extends - super - overriding - overloading - abstract - default methods - SOLID**
Single-class inheritance with multiple interfaces, dynamic dispatch, abstract classes, interface default and private methods, and the SOLID principles with Java examples.

### [Enums, Inner Classes and Packages](enums-inner-classes-packages.md)
**enum - ordinal - nested classes - anonymous classes - singleton - package access**
Enum declarations with fields and behaviour, the four kinds of inner class, the singleton pattern, and how packages control access.

### [Exceptions](exceptions.md)
**Throwable - checked vs unchecked - try-with-resources - custom exceptions - stack traces**
The exception hierarchy, checked and unchecked exceptions, `try`, `catch`, and `finally`, try-with-resources, and how to design and chain exceptions.

### [Generics](generics.md)
**type parameters - bounded types - wildcards - PECS - type erasure**
Generic classes and methods, bounded type parameters, `? extends` and `? super` wildcards, the PECS rule, and what type erasure means at run time.
