# Advanced DSA

Advanced data structures and algorithm techniques from roadmap section 4: graphs, dynamic programming, recursion and backtracking, and greedy, bit manipulation and hashing. Read these after the foundations in [04a-dsa-foundations](../04a-dsa-foundations/index.md).

---

## Topics

### [Graphs](graphs.md)
**BFS - DFS - Dijkstra - Union-Find - topological sort - MST**
Graph representations, traversals, shortest paths, spanning trees, and cycle detection, with a guide to choosing an algorithm.

### [Dynamic Programming](dynamic-programming.md)
**memoisation - tabulation - knapsack - LCS - state design**
Overlapping subproblems and optimal substructure, top-down versus bottom-up DP, and the classic problems.

### [Backtracking and Recursion](backtracking-recursion.md)
**base case - choose and undo - permutations - N-Queens - pruning**
Recursion basics, stack limits, and the backtracking template with permutation and N-Queens examples.

### [Greedy, Bit Manipulation and Hashing](greedy-bit-manipulation-hashing.md)
**greedy choice - XOR - bit masks - equals and hashCode - collisions**
When greedy is safe, common bit tricks, hash table behaviour, and suffix arrays at a conceptual level.
