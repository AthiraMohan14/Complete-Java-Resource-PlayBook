# DSA Foundations

The core data-structure and pattern topics that most coding interviews start from: arrays and strings, linked lists, stacks and queues, and trees. Graphs and dynamic programming are covered in the advanced folder.

---

## Topics

### [Arrays & Strings](arrays-strings.md)
**two pointers - sliding window - binary search - prefix sums - KMP - Rabin-Karp**
Index-based patterns that turn nested loops into single passes, plus binary search variants and string matching.

### [Linked Lists](linked-lists.md)
**singly - doubly - circular - reverse - Floyd cycle detection - dummy node**
Pointer manipulation on singly, doubly, and circular lists, with the classic fast-and-slow pointer techniques.

### [Stacks & Queues](stacks-queues.md)
**ArrayDeque - monotonic stack - monotonic queue - PriorityQueue - next greater element**
Last-in-first-out and first-in-first-out structures, and the monotonic patterns that solve many "nearest" and "window" problems.

### [Trees](trees.md)
**binary tree - BST - traversals - Morris traversal - LCA - path sum - serialisation**
Recursive and iterative traversals, search trees, balanced trees, and the common tree problems asked in interviews.
