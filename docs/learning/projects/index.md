# Projects

Reading builds knowledge, but interviewers and hiring managers look for working software. These pages describe substantial projects to build after the core topics, a ladder of smaller exercises to get there, and the standards your portfolio should meet.

---

### [Hands-On Project Ladder](hands-on-project-ladder.md)
**beginner - intermediate - advanced - capstone - skills per level**
Build small Java programs in order, each reinforcing the topics before it, ending with a mini backend core.

### [E-Commerce Platform](ecommerce-platform.md)
**JWT - OAuth 2.0 - catalogue search - orders - payments sandbox - load testing**
A storefront with authentication, search, cart, orders, payments in a sandbox, and an admin dashboard.

### [Social Feed System](social-feed-system.md)
**feed generation - caching - WebSockets - message queues - Kubernetes - tracing**
A follow-based feed with personalised ranking, real-time notifications, and a split into services.

### [Multi-Tenant SaaS Application](saas-application.md)
**tenant isolation - billing (test mode) - API-first - CI/CD - Terraform - migrations**
A product that serves many organisations safely, with subscriptions, analytics, documented APIs, and automated delivery.

### [Portfolio Requirements](portfolio-requirements.md)
**code quality - documentation - git history - live demo - performance - security**
The checklist every project should meet before you show it to an employer.
