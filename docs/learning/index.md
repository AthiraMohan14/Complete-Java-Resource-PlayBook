## How to Study a Topic

1. Read the topic page from start to finish.
2. Run each code example yourself. Change one thing and predict the result before you run it.
3. Read the **Common pitfalls** and **Interview tip** boxes.
4. Answer the matching questions in [Interview Questions](../interview-questions/index.md) without looking at the answers.
