# Modern Java (8 to 21)

Notes on the language features added from Java 8 onward: lambdas, streams, `Optional`, records, sealed types, pattern matching, and virtual threads. Interviewers use these to check whether you write current Java or only the Java 6 style you learned first.

**Optional - null safety - Predicate - Function - Supplier - Consumer**

### [Java 9 to 17 Features](java9-to-17-features.md)
