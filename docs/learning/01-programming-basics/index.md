# Programming Basics

Start here. This folder covers what Java is, how the JVM and JDK fit together, how to set up a working environment, and the syntax, types, operators, and control flow that every later topic depends on. It also covers the everyday tools (Git, IDEs, and the command line) you will use throughout.

---

## Topics

### [Java Overview and Platform](java-overview-platform.md)
**JVM - JRE - JDK - bytecode - heap - garbage collection - class loading**
What Java is, how the platform layers fit together, JVM memory areas, garbage collectors, class loaders, and the Java SE, Jakarta EE, and Java ME editions.

### [Environment Setup](environment-setup.md)
**JDK - JAVA_HOME - PATH - java -version - javac -version**
Installing a JDK, setting JAVA_HOME and PATH on Windows, macOS, and Linux, and confirming that the setup works.

### [Syntax Basics](syntax-basics.md)
**main - javac - java - naming - keywords - Unicode - Scanner - casting**
Program structure, the compile-then-run flow, naming rules, comments, console input, methods and scope, and type casting.

### [Data Types and Variables](data-types-variables.md)
**primitives - default values - reference types - scope - access modifiers**
The eight primitive types with sizes and defaults, reference types, the three kinds of variables, and the access and non-access modifiers.

### [Operators and Control Flow](operators-control-flow.md)
**precedence - short-circuit - switch expressions - loops - labels**
Arithmetic, logical, bitwise, and ternary operators; operator precedence; if and switch; loops; and break and continue.

### [Git, IDEs and Command-Line Tools](git-ide-tools.md)
**git - branch - merge conflict - IntelliJ IDEA - Eclipse - VS Code - jshell - javadoc**
The everyday Git workflow, the common Java IDEs, and the command-line tools for compiling, running, documenting, and experimenting.
